# Doubts Log

Written by **main Claude** when a doubt reveals a misunderstanding (not for simple
clarifications). Read by **`lld-mentor`** when curating quizzes/exercises.

Format — one entry per doubt, newest at the bottom:

```
- YYYY-MM-DD | <topic-slug> | <the doubt, one line> | misconception: <what was wrong, one line> | status: open
```

`lld-mentor` changes `status: open` → `status: pitfall:<id>` once it has turned the entry
into a pitfall in progress.json, or `status: used` once it has targeted it in a quiz/exercise.
